En bref

OpenMausBot est une application de chat open source, inspirée de Grok Bot. Chaque bot de la barre latérale est un vrai agent (Claude ou Codex en local) avec sa personnalité, son modèle, son ordinateur cloud et ses applications connectées.

Elle s'adresse à ceux qui veulent une équipe d'assistants IA plutôt qu'un seul, sur leur propre machine. Les bots utilisent les CLI claude, codex et grok déjà installés, donc tes abonnements existants. Les transcriptions et les clés restent dans ~/.openmausbot, et des cartes d'approbation te laissent valider les actions importantes.

Pour commencer, télécharge l'application pour Mac (Apple silicon ou Intel), Windows ou Ubuntu depuis la page des releases du dépôt. Le projet est sous licence Apache-2.0, usage commercial autorisé. Plus de cinq cents applications se connectent via Composio.
